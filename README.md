# ComiCine

> Built like infrastructure. Captured like art.

ComiCine is [Lime](https://github.com/Lime-ComiCine/)'s independent creative studio, bringing software development and visual storytelling together. We build web products and infrastructure, and create photography and video inspired by light, place, and everyday stories.

## About Lime

Lime is a student, web developer, photographer, and video creator. ComiCine is where these interests meet: practical software projects alongside creative work.

- Currently studying IGCSE while building independent projects
- Uses [Codex](https://openai.com/codex/) and to turn ideas into working software
- Interested in web development, photography, video, and creative technology
- Open to thoughtful collaborations and interesting experiments

## What We Do

### Software and Web

ComiCine builds websites, web applications, and supporting services. Projects range from public websites and multilingual documentation to serverless services running at the network edge.

We value clear interfaces, useful features, reliable infrastructure, and careful implementation. AI-assisted tools are part of the workflow, with project documentation and engineering practices guiding how ideas become finished products.

### Photography and Video

Photography and video are an important part of ComiCine's creative work. They offer a way to notice details, capture atmosphere, and tell stories through light and motion.

- Photography projects and services
- Video creation and online content
- Creative experiments that connect visual work with technology

## Source Repository

### [ComiCine-website source repository](https://github.com/ComiCine/ComiCine-website/)

This repository contains the full-stack source for the website and its supporting services. The platform runs on Cloudflare Pages Functions, Workers, D1, and R2.

- Turnstile human verification for browser visitors
- Protected visitor analytics and Apple Account management tools
- Shared identity services for protected areas
- A four-language status page with scheduled checks and webhook alerts
- Portfolio image delivery that keeps originals private while publishing watermarked images and clean thumbnails
